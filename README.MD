# Ciqueus 


Um sistema de banco de questões de provas de concurso e vestibulares que servirá de API open-source.

## Funções do sistema

* Identificar a prova
    * Identificar por PDF
    * Identificar por foto

* Registrar questões 

## Tecnologias e Linguagens

* Poppler: um conjunto de ferramentas escrito em C++ para lidar com PDF.

* JavaScript
* Python
* HTML5
* CSS3 (Bootstrap)


## Fluxo de Trabalho

Questões acrescentar 
-> Clica no botão "Adicionar questão" -> Importa o PDF da prova -> Importa o gabarito da prova -> Faz uma comparação com um dicionário questao-gabarito -> Finaliza o acréscimo da questão
