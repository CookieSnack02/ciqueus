# Ciqueus 


Um sistema de banco de questões de provas de concurso e vestibulares que servirá de API open-source.

## Funções do sistema

* Identificar a prova
    * Identificar por PDF
    * Identificar por foto

* Registrar questões 

## Tecnologias e Linguagens

* OCR 

* JavaScript
* Python
* HTML5
* CSS3 (Bootstrap)
